## 💡 한눈에 보는 핵심 요약 (Q&A)

### 1. HTML 시맨틱 태그 (의미 있는 태그)
*   **왜 쓰나요?** 
    *   초록창이나 구글 같은 **검색엔진이 내 사이트를 더 잘 찾게 만들고**, 화면 읽기 도구(스크린 리더)가 사이트 구조를 쉽게 해석할 수 있도록 돕기 위해서입니다.
*   **어떤 기준으로 설계했나요?**
    *   전체 틀은 머리(`header`), 본문(`main`), 꼬리(`footer`)로 크게 쪼갰습니다.
    *   본문 안에서는 소개, 기술, 연락처 등 주제가 바뀔 때마다 `section`으로 나누고, 개별 프로젝트 카드는 독립된 콘텐츠이므로 `article`을 사용했습니다.

---

### 2. Flexbox vs Grid 차이점
*   **Flexbox (1차원 줄 세우기):** 가로나 세로 중 **한 방향** 정렬에 씁니다. (예: 메뉴 바에서 로고는 왼쪽, 메뉴는 오른쪽에 나란히 배치할 때)
*   **Grid (2차원 바둑판):** 가로와 세로 **줄 맞춘 격자판**에 씁니다. (예: 가로세로 줄을 맞춰 예쁘게 정렬해야 하는 프로젝트 카드 목록에 사용)

---

### 3. DOM 선택과 이벤트 연결 흐름
*   **어떻게 작동하나요?**
    1.  `querySelector`로 제어하고 싶은 HTML 요소를 콕 집어 가져옵니다.
    2.  `addEventListener`로 그 요소에 "클릭하면 이 함수를 실행해줘"라고 감시 센서를 달아둡니다.
    3.  사용자가 클릭하는 순간, 센서가 작동해 준비된 자바스크립트 기능이 실행됩니다.

---

### 4. 핵심 JS 문법 (화살표 함수, 구조분해, map/filter)
*   **왜 쓰고 어떻게 쓰나요?**
    *   **화살표 함수 (`() => {}`):** 코드를 훨씬 짧고 깔끔하게 쓰기 위해 사용합니다.
    *   **구조분해 할당:** `repo.name`, `repo.url`처럼 길게 쓰던 것을 `const { name, url } = repo`로 한 번에 꺼내 편하게 씁니다.
    *   **map / filter:** 
        *   `filter`로 내가 원하는 프로젝트(예: Fork 되지 않은 저장소)만 쏙 골라내고,
        *   `map`을 돌려 골라낸 데이터를 예쁜 카드 모양 HTML 태그로 변환했습니다.

---

### 5. fetch 비동기 통신과 4가지 화면(UI) 상태
데이터를 받아오는 동안 브라우저가 멈추지 않도록 비동기(`fetch`, `async/await`)로 처리했습니다.
*   **로딩 중:** 데이터를 가져오는 동안 "불러오는 중..." 글자나 빙글빙글 도는 아이콘을 보여줍니다.
*   **성공:** 정상적으로 받아오면 프로젝트 카드 목록을 화면에 띄웁니다.
*   **실패 (에러):** 네트워크가 끊기거나 제한을 초과하면 "다시 시도" 버튼을 보여줍니다.
*   **빈 상태:** 받아온 프로젝트가 하나도 없다면 "보여줄 프로젝트가 없습니다"라고 알려줍니다.

---

### 6. [이벤트 ➔ 상태 변경 ➔ 화면 업데이트] 흐름
"버튼 클릭"이 화면 변화로 이어지는 3단계 과정입니다. (예: 다크 모드)
1.  **이벤트:** 사용자가 테마 전환 버튼을 클릭합니다.
2.  **상태 변경:** 자바스크립트가 현재 상태를 `light`에서 `dark`로 바꿉니다.
3.  **화면 업데이트:** 바뀐 상태에 맞춰 화면 전체에 다크 모드 스타일(CSS)을 적용합니다.
> 💡 **핵심:** 요소를 직접 억지로 바꾸는 것이 아니라, **"상태(데이터)를 바꾸면 화면은 알아서 그 상태를 따라 변하게 만든다"**는 개념을 적용했습니다. (React의 기본 원리)
