```
# 1. 저장소 초기화
init "Alice"

# 2. 커밋 생성
commit "First commit"

# 3. 브랜치 생성 및 전환
branch "feature-a"
switch "feature-a"
commit "Second commit"

SWITCH "main"
commit "Third commit"

# 4. 로그 확인 (정렬 확인)
log
log --sort-by=date
log --sort-by=author

# 5. 경로 탐색 (앞서 생성한 해시 값을 확인 후 입력)
path <첫번째_커밋_해시> <세번째_커밋_해시>

# 6. 조상 커밋 확인
ancestors <세번째_커밋_해시>

# 7. 검색 기능
search "Third"
search --author="Alice"

# 8. 종료
exit
```
```
## 평가 항목 보완 설명

### #1 INIT
`INIT` 실행 시 저장소를 초기화하고 `main` 브랜치를 생성하며 HEAD를 `main`으로 설정하고 현재 사용자를 지정합니다.

### #2 BRANCH / SWITCH / COMMIT
BRANCH와 SWITCH는 브랜치 생성 및 전환하고, COMMIT 실행 시 새로 생성된 커밋의 hash를 출력하며 현재 HEAD를 부모 커밋으로 연결합니다.

### #3 LOG
`LOG`는 커밋 그래프를 탐색하여 부모 커밋이 자식 커밋보다 먼저 출력되도록 위상 정렬 방식으로 결과를 구성합니다.

### #4 PATH
`PATH`는 커밋과 부모 관계를 무방향 간선으로 변환한 뒤 BFS로 최소 간선 수의 최단 경로를 찾으며, 경로가 없으면 `No path`를 출력합니다.

### #5 ANCESTORS
`ANCESTORS`는 지정한 커밋에서 부모 방향으로 DFS를 수행하여 도달 가능한 모든 조상 커밋을 중복 없이 출력하며, 부모가 여러 개인 merge commit도 처리합니다.

### #6 SEARCH / SORT 옵션
`SEARCH`의 키워드는 소문자로 정규화하여 검색하고, `--author`는 작성자 역색인을 사용하며, `LOG --sort-by=date|author`는 지정한 기준으로 직접 구현한 정렬 알고리즘을 사용합니다.

### #7 저장소 구조와 HEAD
저장소는 `commits`, `branches`, `HEAD`, `current_user`를 독립적으로 관리하며, HEAD는 현재 브랜치 이름을 통해 현재 작업 위치를 결정하는 역할을 담당합니다.

### #8 HashMap과 충돌
커밋은 hash를 키로 저장하며, hash 충돌 가능성을 고려하여 세션 내 중복 hash가 발생하지 않도록 고유 ID 생성 규칙을 적용합니다.

### #9 역색인
커밋 생성 시 메시지를 공백 기준으로 분리하고 소문자로 정규화한 키워드와 작성자를 각각 역색인에 등록하여 검색 시 전체 커밋 순회를 피합니다.

### #10 그래프 탐색 공통화
LOG, PATH, ANCESTORS에서 사용하는 커밋 그래프 탐색 로직을 독립 함수로 분리하여 동일한 그래프 자료구조를 재사용합니다.

### #11 Docstring
주요 클래스와 함수에는 docstring을 작성하여 입력값, 반환값, 주요 동작과 부작용을 명확하게 설명합니다.

### #12 DAG와 이력 불변성
커밋은 기존 커밋을 수정하지 않고 새로운 노드만 추가하며 부모는 항상 이미 존재하는 커밋을 가리키므로 커밋 그래프의 DAG 구조와 이력 불변성을 유지합니다.

### #13 LOG 위상 정렬
`LOG`는 자식 커밋보다 부모 커밋이 먼저 출력되도록 DFS 후위 방문 또는 위상 정렬 방식으로 출력 순서를 구성합니다.

### #14 PATH BFS
`PATH`에서는 부모 방향 그래프를 양방향 인접 관계로 구성하고 BFS를 사용하여 간선 수가 최소인 경로를 탐색합니다.

### #15 직접 구현 정렬
Python의 `sorted()`와 `list.sort()`를 사용하지 않고 직접 구현한 정렬 알고리즘을 사용하며, 날짜와 작성자를 비교 기준으로 전달할 수 있도록 구성합니다.

### #16 역색인 복잡도
키워드와 작성자별로 커밋 hash 목록을 저장하는 역색인을 사용하여 검색 시 전체 커밋을 순회하지 않고 후보 목록을 직접 조회할 수 있도록 구현했습니다.
```
